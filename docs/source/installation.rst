##############
 Installation
##############

The most recent release can be installed from `PyPI
<https://pypi.org/project/functional-owl>`_ with uv:

.. code-block:: console

    $ uv pip install functional-owl

or with pip:

.. code-block:: console

    $ python3 -m pip install functional-owl

*********************
 Installing from git
*********************

The most recent code and data can be installed directly from GitHub with uv:

.. code-block:: console

    $ uv pip install git+https://github.com/cthoyt/functional-owl.git

or with pip:

.. code-block:: console

    $ python3 -m pip install git+https://github.com/cthoyt/functional-owl.git

****************************
 Installing for development
****************************

To install in development mode with uv:

.. code-block:: console

    $ git clone git+https://github.com/cthoyt/functional-owl.git
    $ cd functional-owl
    $ uv pip install -e .

or with pip:

.. code-block:: console

    $ python3 -m pip install -e .
